# mercurius-mcp-gemini-api

MCP-сервер по stdio для медиа-моделей Google по ключу Gemini API: картинки, речь, музыка, видео, транскрипция,
анализ файлов и фоновые исследовательские агенты. Это модуль [Меркурия](https://github.com/opencck/mercurius) на
[AMPHP](https://amphp.org). Сам сервер запросов к Google не делает: каждый вызов инструмента — один запуск
официального клиента [gemini-api CLI](https://github.com/google-gemini/gemini-api-cli) закреплённой версии.

Клиент работает только по ключу API; каждый вызов оплачивается по прайсу Gemini API. К подписке Google он отношения
не имеет.

## Инструменты

| Инструмент | Что делает | Пометка |
|------------|------------|---------|
| `image` | Делает картинку по описанию, возвращает файл | не разрушает |
| `speech` | Озвучивает текст дословно, возвращает WAV | не разрушает |
| `music` | Делает музыку, возвращает файл | нет: клиент спрашивает владельца |
| `video_start` | Запускает создание видео, возвращает id операции | нет: клиент спрашивает владельца |
| `video_result` | Ждёт запущенное видео до минуты, возвращает файл | только чтение |
| `transcribe` | Расшифровывает аудио и видео в текст | только чтение |
| `analyze` | Отвечает на вопрос по файлам или видео YouTube | только чтение |
| `research_start` | Запускает фонового исследовательского агента (Deep Research), возвращает id запуска | нет: клиент спрашивает владельца |
| `research_status` | Читает состояние и отчёт запуска | только чтение |
| `models_list` | Модели каталога CLI: что каждая делает и каким инструментом вызывается (договор Меркурия) | только чтение |

Файлы передаются как `files: [{name, content_base64}]` (до 10 файлов и 14 МБ на вызов) и возвращаются вложенными
ресурсами (до 20 МБ каждый).

## Установка

```bash
composer install --no-dev
```

После установки `bin/fetch-binary` скачивает релиз из `binary.lock.json` для Linux `x86_64` или `arm64`, сверяет
sha256 и кладёт бинарь в `vendor/gemini-api/`. На другой системе или с `GEMINI_API_SKIP_FETCH=1` ничего не
скачивается; тогда укажите свой бинарь в `GEMINI_API_BIN`.

## Запуск

```json
{
  "mcpServers": {
    "gemini-api": {
      "command": "php",
      "args": ["/path/to/bin/gemini-api-mcp"],
      "env": { "GEMINI_API_KEY": "..." }
    }
  }
}
```

| Переменная | Что это |
|------------|---------|
| `GEMINI_API_KEY` | Ключ Gemini API (Google AI Studio). Без него сервер запускается и на каждый вызов отвечает, чего не хватает |
| `GEMINI_API_BIN` | Другой бинарь вместо закреплённого; несколько слов — команда с первыми аргументами |
| `GEMINI_API_TIMEOUT` | Секунд на один запуск бинаря: по умолчанию 100, не больше 900 |
| `GEMINI_API_PROXY` | Выход бинаря в сеть: адрес прокси (`http://`, `socks5h://`) или слово `direct`. Пусто: прокси записи (ниже), иначе дверь установки Меркурия `http://vless-proxy:8080`, когда она слушает (ведёт в VLESS установки или в её прокси), иначе напрямую |
| `HTTPS_PROXY`, `HTTP_PROXY`, `NO_PROXY` | Прокси записи, передаются бинарю |

В Меркурии сервер идёт в поставке; ключ — секрет агента, подставленный в запись `.mcp.json` как `{GEMINI_API_KEY}`.

## Безопасность

- Ключ живёт в окружении процесса, не в аргументах; бинарь получает ключ, домашний каталог внутри каталога вызова
  и путь поиска — и ничего больше из окружения сервера.
- Текст, написанный моделью, не может стать флагом: промпт идёт после `--` или через stdin, короткие значения
  проверяются по образцу, ссылка YouTube должна вести на одно видео YouTube.
- Каждый вызов работает в своём временном каталоге, который удаляется после ответа; от имени файла, названного
  агентом, берётся последняя часть и безопасные символы.
- Версия бинаря и sha256 его архива закреплены.

## Проверки

```bash
composer check   # PHPUnit, PHPStan (max), Psalm (уровень 1); без сети, вместо бинаря — подставной
```

Сервер проверен на подставном бинаре: живого ключа на момент написания не было. Что осталось проверить — в
`BRIEF.md`.
